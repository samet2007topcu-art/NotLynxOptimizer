v1.0 10 KERNEL MODÜLÜ

NotLynx Optimizer v1.0 içerisinde yer alan ve sisteminizi uçuran 10 profesyonel optimizasyon modülünün detaylı dökümü:

[01 / 10] BCDedit

Sistem Zamanlayıcısı

BCDedit parametreleri kusursuzlaştırılarak micro-stutter önlenir ve çekirdek saat senkronizasyonu kararlı hale getirilir.

bcdedit /set useplatformclock false
[02 / 10] Ağ & Ping

Network Throttling Önceliği

Ağ bant genişliği tamamen oyun trafiğine rezerve edilerek ping dalgalanmaları ve paket kayıpları sıfırlanır.

NetworkThrottlingIndex = 0xFFFFFFFF
[03 / 10] TCP/IP

TCP No Delay (Nagle)

Nagle algoritması devre dışı bırakılarak TCP paket gecikmesi ve sunucu yanıt süresi minimum seviyeye indirilir.

TcpAckFrequency = 1 | TCPNoDelay = 1
[04 / 10] RAM & Bellek

DisablePagingExecutive

Çekirdek sürücüler RAM'de tutularak sayfalama gecikmesi (DPC latency) dramatik ölçüde düşürülür.

DisablePagingExecutive = 1
[05 / 10] CPU Scheduler

CPU Ön Plan Önceliği

İşlemci gücü arka plan servislerinden alınıp doğrudan aktif oyun penceresine ve ön plan görevlerine tahsis edilir.

Win32PrioritySeparation = 26
[06 / 10] GPU MMCSS

GPU Oyun Görev Önceliği

Multimedia Tasks (MMCSS) yapılandırılarak ekran kartı (GPU) önceliği maksimum seviyeye çıkarılır.

MMCSS Games Priority = High
[07 / 10] USB & Raw Input

Fare Gecikmesi Sıfırlama

USB güç tasarrufu kapatılır, Raw Input aktif edilerek 1:1 e-spor fare hassasiyeti ve sıfır gecikme sağlanır.

USB Selective Suspend = Disabled
[08 / 10] Services Shield

Telemetry & SysMain Kapatma

DiagTrack, SysMain ve disk yoran arama indeksleme servisleri durdurularak disk darboğazı önlenir.

sc config SysMain start= disabled
[09 / 10] Xbox DVR

FPS Drop Kayıt Kancaları

Arka planda çalışan Xbox Game DVR ve ekran kaydı kancaları tamamen devre dışı bırakılır.

AllowGameDVR = 0
[10 / 10] Ultimate Power

Nihai Performans Modu

İşlemci frekans kilitleri tamamen açılır ve Turbo Boost parametreleri maksimum performans için optimize edilir.

powercfg -duplicatescheme e942b02...
